# 🚰 Miami Flow Plumbing — Professional Web Application

A modern, high-performance web application built for a residential and commercial plumbing contracting company in Miami, Florida. Features cutting-edge interactive WebGL graphics, scroll-driven SVG animations, and a seamless estimate booking engine.

---

## ✨ Key Features & Highlights

- **3D WebGL Fluid Canvas (`Three.js`)**: Interactive 3D neon pipe background that moves dynamically with cursor physics and includes 4 selectable fluid palettes (*Miami Cyan*, *Deep Sea*, *Aqua Emerald*, and *Electric Coral*).
- **Scroll-Driven SVG Journey Line**: An interactive 6-step service process pipeline that dynamically draws itself forward in real time matching the user's scroll percentage with a built-in interactive scrub controller.
- **Before / After Comparison Sliders**: Visual proof of real pipe restorations, slab leak reroutes, and tankless heater conversions.
- **Interactive Multi-Step Estimate Modal**: Custom plumbing cost estimator with service type selection, urgency indicators, photo uploads, and upfront pricing.
- **Searchable FAQ Knowledge Hub**: Instant search and category-filtered answers covering Miami-specific plumbing challenges (cast iron sewer lines, limestone hard water, and hurricane prep).
- **Mobile-First UX**: Floating sticky quick-dispatch emergency bar with one-touch phone dialers and WhatsApp integration.
- **SEO & Schema.org Optimized**: Pre-configured JSON-LD `PlumbingContractor` structured data for local Miami-Dade search engines.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **3D Graphics**: Three.js (`three` & `@types/three`)
- **Animations**: Motion (`motion/react`)
- **Icons**: Lucide React
- **Deployment**: Ready for Vercel, Netlify, and Cloud Run (`vercel.json` included)
